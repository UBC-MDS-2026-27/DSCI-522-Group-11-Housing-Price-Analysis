import os
import pandas as pd
import altair as alt
from sklearn.model_selection import train_test_split

Methods

Data acquisition

The raw data are saved, unmodified, in data/raw/.

data = "../data/raw/AmesHousing.csv"
raw = pd.read_csv(data)

Cleaning

We keep the target (sale price) and the three features in our question, living area, overall quality, and house age. We give them more readable and consistent names. Instead of the year a house was built, we use its age, calculated as the reference year (2026) minus the year built, so that the feature is a number of years. The cleaned data is saved as a csv.

cleaned = raw[["Gr Liv Area", "Overall Qual", "SalePrice"]].copy()
cleaned.columns = ["living_area", "overall_quality", "sale_price"]
cleaned["house_age"] = 2026 - raw["Year Built"]

os.makedirs("../data/processed", exist_ok=True)
cleaned.to_csv("../data/processed/ames_cleaned.csv", index=False)

Training and Testing Data

We are separating the train and test data with 80: 20 ratio. We are doing this before any exploratory analysis so the test set cannot influence our decisions and there is no leakage.

train_df, test_df = train_test_split(
    cleaned, test_size=0.2, random_state= 552
)

train_df.to_csv("../data/processed/ames_train.csv", index=False)
test_df.to_csv("../data/processed/ames_test.csv", index=False)

Exploratory Data Analysis (EDA)

labels = {
    "living_area": "Living area (sq ft)",
    "house_age": "House age in 2026 (years)",
    "overall_quality": "Overall quality (1-10)",
    "sale_price": "Sale price (US$)",
}
features = ["living_area", "house_age", "overall_quality"]

summary = (
    train_df[features + ["sale_price"]]
    .describe()
    .T[["count", "mean", "std", "min", "50%", "max"]]
    .rename(columns={"50%": "median"})
)
summary["corr. with price"] = train_df.corr()["sale_price"]
summary.loc["sale_price", "corr. with price"] = None
summary = summary.rename(index=labels).round(2)
summary
points_area = alt.Chart(train_df).mark_circle(opacity=0.25).encode(
    x=alt.X("living_area", title="Living area (sq ft)"),
    y=alt.Y("sale_price", title="Sale price (US$)"),
)
line_area = points_area.transform_regression("living_area", "sale_price").mark_line(color="red")
chart_area = points_area + line_area

points_age = alt.Chart(train_df).mark_circle(opacity=0.25).encode(
