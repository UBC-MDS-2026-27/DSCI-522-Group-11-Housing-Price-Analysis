Methods

Overview of the approach

We used Python with pandas for data handling, scikit-learn for the split, pipeline, and model (Pedregosa et al., 2011), and Altair for the figures (VanderPlas et al., 2018). We followed the same steps in order, and we describe each below. First, we downloaded the data from its original source and saved an unmodified copy. Second, we selected and cleaned the four columns we need and saved the result. Third, before looking at the data in any detail, we split it into a training set (80%) and a test set (20%). Fourth, we explored the training set only, with summary statistics and a plot. Fifth, we built a preprocessing and modelling pipeline and compared a baseline to a multiple linear regression using five-fold cross-validation on the training set. Last, we evaluated the final model once on the test set.

Model and metrics

We use multiple linear regression, which predicts the price as a weighted sum of the features plus an intercept. We chose it for three reasons. It matches our question directly, because each fitted weight (coefficient) states how many dollars of price are associated with one more unit of a feature when the others are held fixed. It follows the hedonic pricing tradition described in the Introduction (Rosen, 1974). And it is a transparent, easily explained method that works as a sensible first model on a data set of this size (Hastie et al., 2009). To judge whether the model has learned anything useful, we compare it with a baseline that ignores all features and predicts the average training price for every house.

Our main metric is the root mean squared error (RMSE). It is the square root of the average squared difference between predicted and actual prices, so it is measured in US dollars and can be read as the size of a typical prediction error, with large errors counting extra. We chose it because the target is a dollar amount, so an error in dollars is easy to interpret, and because large mistakes on expensive houses are particularly costly. As a secondary metric we report R², the share of the variation in price that the model explains (0 means no better than predicting the mean, 1 means perfect). On the test set we also report the mean absolute error (MAE), the average size of the error without extra weight on large errors.

Cleaning

We keep the target (sale price) and the three features in our question: living area, overall quality, and house age. We rename them to more readable, consistent names. Instead of the year a house was built we use its age, calculated as the reference year (2026) minus the year built, so that the feature is a number of years that is easy to interpret. The cleaned data are saved in data/processed/.

cleaned = raw[["Gr Liv Area", "Overall Qual", "SalePrice"]].copy()
cleaned.columns = ["living_area", "overall_quality", "sale_price"]
cleaned["house_age"] = 2026 - raw["Year Built"]

os.makedirs("../data/processed", exist_ok=True)
cleaned.to_csv("../data/processed/ames_cleaned.csv", index=False)

Training and testing data

We split the data 80% / 20% into training and test sets (2,344 and 586 houses) with a fixed random seed so that the split can be reproduced. We do this before any exploratory analysis or preprocessing, so that the test set cannot influence any decision we make, which avoids leaking information from the test set into the model. From this point on, the test set is used only once, for the final evaluation.

train_df, test_df = train_test_split(cleaned, test_size=0.2, random_state=552)

train_df.to_csv("../data/processed/ames_train.csv", index=False)
test_df.to_csv("../data/processed/ames_test.csv", index=False)

Preprocessing pipeline and baseline

All three features are numeric, and we keep them in their original units (linear regression does not require rescaling, and the original units let us read the coefficients directly in dollars). None of the four columns has missing values in this data, but we include median imputation in the pipeline as a safeguard so that the same pipeline would still work on data with gaps. The imputer is fitted inside each cross-validation fold, so no information leaks from the held-out fold.

We evaluate the mean-prediction baseline using five-fold cross-validation within the training set: the training set is divided into five parts, and each part in turn is held out while the model is fitted on the other four. In each fold, the baseline predicts the mean price of that fold’s training houses.

numeric_features = ["living_area", "house_age", "overall_quality"]

X_train = train_df[numeric_features]
y_train = train_df["sale_price"]
X_test = test_df[numeric_features]
y_test = test_df["sale_price"]

preprocessor = ColumnTransformer(
    transformers=[("numeric", SimpleImputer(strategy="median"), numeric_features)],
    remainder="drop",
)

dummy_pipeline = Pipeline(
    steps=[("preprocessor", preprocessor), ("regressor", DummyRegressor(strategy="mean"))]
)

cv = KFold(n_splits=5, shuffle=True, random_state=552)
scoring = {"rmse": "neg_root_mean_squared_error", "r2": "r2"}

dummy_cv = cross_validate(
    dummy_pipeline, X_train, y_train, cv=cv, scoring=scoring, error_score="raise"
)

# scikit-learn reports errors as negative numbers; convert RMSE back to positive dollars
fold_scores = pd.DataFrame(
    {"RMSE (US$)": -dummy_cv["test_rmse"], "R-squared": dummy_cv["test_r2"]}
)

Main model: multiple linear regression

We fit the multiple linear regression using the same predictors, preprocessing, and five cross-validation folds as the baseline, so the two are compared fairly. We did not tune anything and did not choose between models using the test set. The test set is reserved for the final evaluation.

linear_pipeline = clone(dummy_pipeline).set_params(regressor=LinearRegression())

linear_cv = cross_validate(
    linear_pipeline, X_train, y_train, cv=cv, scoring=scoring, error_score="raise"
)

linear_fold_scores = pd.DataFrame(
    {"RMSE (US$)": -linear_cv["test_rmse"], "R-squared": linear_cv["test_r2"]}
)

Finally, we fit the pipeline on the full training set and evaluate it once on the held-out test set. The coefficients come from this final fit.

linear_pipeline.fit(X_train, y_train)
linear_test_predictions = linear_pipeline.predict(X_test)

dummy_final = clone(dummy_pipeline).fit(X_train, y_train)
dummy_test_predictions = dummy_final.predict(X_test)

Result

Exploring the training data

Table 1 shows the training data. Houses in the training set have a median living area of 1,450 sq ft, a median age of 53 years, and a median overall quality of 6 out of 10, with a mean price of about US$181,000. All three features are associated with price in the expected direction. Overall quality has the strongest correlation with price (0.80), followed by living area (0.70), while age has a moderate negative correlation (−0.56). Figure 1 shows these relationships: price rises with living area and with quality (more steeply at the higher quality ratings), and falls with age. Figure 1 also shows that the spread of prices is wider for bigger, newer, and higher-quality houses, and that a handful of very large houses sell at much lower prices than the trend suggests (five training houses have more than 4,000 sq ft of living area, and three of them sold for less than US$190,000).

The three features are also related to each other in the training data. Overall quality is moderately correlated with living area (0.57) and negatively correlated with age (−0.60), so newer houses tend to be rated higher. This is relevant for interpreting the model below.

The baseline has an RMSE of about US$80,000 and an R² of essentially zero (−0.004), which is what we expect from a model that always predicts the average; its R² is very slightly negative because each fold’s average is not exactly the average of the held-out fold. The linear regression reduces the RMSE to about US$39,800, roughly half the baseline error, and raises R² to about 0.75. The fold-to-fold variation (a standard deviation of about US$4,700 in RMSE) is much smaller than the gap between the two models, so the improvement is not an accident of one particular fold.

Discussion

Summary of findings

Our question was how well the living area, the age, and the overall quality of a house predict its sale price in Ames, and how each feature is associated with price. The answer is that these three features alone predict sale price reasonably well. A multiple linear regression cut the typical prediction error roughly in half compared with always guessing the average price (a test RMSE of about US$38,600 against about US$78,900), and it explained about 76% of the variation in sale prices of houses it had not seen. The cross-validation and test results agree, so we have no sign of overfitting. Quality, size, and age each contribute in the expected direction when the others are held fixed.

What this means in the real-world context

In practical terms, the model gives a quick “ballpark” price from three facts that are easy to look up. A typical error of around US$39,000 is useful for a first estimate or for flagging properties that look very far from the expected price, but it is too large for the model to replace an appraisal: for a house selling at the mean price, the error is around a fifth of the price. The coefficients also give a concrete way of comparing features. One additional point of overall quality is associated with about as much price as roughly 420 additional square feet of living area (26,400 divided by 62), which suggests that quality of materials and finish is a major driver of value, comparable to substantial additions of space. This is consistent with the hedonic view that buyers pay for a bundle of characteristics (Rosen, 1974; Sirmans et al., 2005).

Was this what we expected?

Partly. We expected price to rise with size and quality and to fall with age, and the signs of all three coefficients agree with this. We also expected quality to be the strongest single predictor, and it was (a correlation of 0.80 with price). What was less obvious was how small the age coefficient is: age had a clear negative correlation with price (−0.56) on its own, but when quality and living area are held fixed, a year of age is associated with only about US$485 less. A likely explanation is that age and quality are strongly related in this data (a correlation of −0.60 in the training set), so much of the apparent effect of age is picked up by the quality rating. We did not test this explanation directly, for example by fitting a model with and without quality, so it should be treated as a hypothesis. We also did not expect the model to produce negative prices, which is a clear sign that a straight-line model is too simple at the low end of the market.

Assumptions and limitations

  • Linearity and additivity. Linear regression assumes that each feature changes the price by the same dollar amount at every level, and that the effects simply add up. Figure 1 suggests this is only approximately true; for example, price rises more steeply at the higher quality ratings. A larger share of the variation might be explained if the model allowed curved relationships or interactions.
  • Unequal error spread. Errors were noticeably larger for expensive houses (Figure 2 and the standard deviations reported in the Results). Linear regression is typically fitted assuming errors of similar size at every price level, so RMSE is a summary that hides the fact that predictions are less reliable for expensive houses. Modelling the logarithm of price is a common remedy that would also rule out negative predictions, but we did not try it, to keep the model’s coefficients interpretable in dollars.
  • Unusual houses. The training data include five houses with more than 4,000 sq ft of living area, three of which sold at low prices for their size. We kept them, because removing observations after seeing the training data is a judgement call we did not want to make without a clear rule, but they can influence the fitted line.
  • Few features. We used only three features. The data set has 82 columns, including the neighborhood, lot size, garage, and basement, and the unexplained 24% of the variation in price is probably due in large part to such missing information. Location in particular is a major driver of house prices, and our model ignores it.
  • The overall quality rating is subjective. It is assigned by an assessor, not measured, and it already reflects judgements about material and finish that may be correlated with price itself.
  • Age is measured from 2026. We computed the age as 2026 minus the year built for all houses, although the houses were sold between 2006 and 2010. This is only a constant shift for each house and does not change the ordering of the ages, but the age at the time of sale would be a more natural measure.
  • Association, not causation. The coefficients describe how prices differ between houses in this data, not what would happen if a particular house were renovated. A higher quality rating is also correlated with features we did not include.
  • Scope. The data describe one small city over five years that include the 2008 financial crisis and housing downturn. The relationships may not hold in other cities, or in the market today.
  • A single split. We evaluated on one random test set of 586 houses. The cross-validation spread (about US$4,700 in RMSE) shows that the exact RMSE depends on which houses are included, so differences of a few thousand dollars should not be over-interpreted.

Impact

Models of this kind could help assessors and lenders to flag properties whose price is very different from what simple characteristics would suggest, and could give first-time buyers and sellers an anchor for negotiation, because the method is simple enough to be explained in a sentence. Because the model is less accurate for expensive houses and ignores location, however, it should be used as a screening or starting tool and not as a substitute for a professional appraisal; relying on it alone could systematically under-value expensive houses and misprice houses in desirable or undesirable neighborhoods.

Future questions

This work leads to several follow-up questions. How much does accuracy improve if we add neighborhood and lot characteristics, and does location matter more than quality? Would predicting the logarithm of price, or using a more flexible method such as a regularized regression or a tree-based model, reduce the large errors for expensive houses and avoid negative predictions (Hastie et al., 2009)? Does the relationship between age and price change when quality is left out of the model, as we suspect? Do the same coefficients hold in other cities and in more recent years? Finally, are the model’s errors spread fairly across neighborhoods and price levels, which matters if such a model were ever used in assessment or lending?
